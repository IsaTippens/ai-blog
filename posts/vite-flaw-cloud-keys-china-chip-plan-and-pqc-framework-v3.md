## I. CLOUD SECURITY & DEVELOPER INFRASTRUCTURE EXPLOITATION

### 1. Mass-Scanning Campaign Exploits Vite Vulnerability (CVE-2026-39364) to Harvest Cloud Keys
Targeting modern frontend build pipelines, [threat actors launched automated internet-wide scanning campaigns exploiting a critical path traversal vulnerability in the Vite development server (CVE-2026-39364)](https://thehackernews.com/2026/09/mass-scanning-campaign-exploits-vite.html). As reported by [SecurityOnline](https://securityonline.info/vite-cve-2026-39364-exploited/), the exploit bypasses development server filesystem confinement when exposed on external interfaces, enabling attackers to siphon `.env` configuration files containing active cloud access keys, database credentials, and internal API tokens.

### 2. AFORPA and Educational Training Infrastructure Disrupted in Ransomware Breach
Exposing technical education networks, [telemetry published by Breachsense revealed that European technical training network AFORPA suffered a targeted ransomware intrusion](https://www.breachsense.com/breaches/). The threat actors exfiltrated internal identity databases and compromised administrative server clusters, highlighting ongoing ransomware pressure against public and vocational infrastructure.
